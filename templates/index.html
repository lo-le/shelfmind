How the choice maths works

Each shopper picks the product with the highest utility U = Σ (behavioural weight × product feature) plus Gumbel noise (a logit model). Social-proof-driven shoppers re-weight toward whatever earlier shoppers already picked, so the swarm can tip. Baseline and promo runs share the same noise (common random numbers), so the difference is the promo's causal effect.
